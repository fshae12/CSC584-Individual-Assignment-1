# CSC584-Individual-Assignment-1
Personal Profile Application using HTML, Java Servlet, JSP and CSS.

## Project Description
This is individual assignment of subject CSC584, a simple Personal Profile Web Application that is developed using HTML, Java Servlet, JSP and CSS style.

This application has minimalist layout and modern color, allows users to enter their personal details  through the HTML form. Then, the submitted details will be process by Java Servlet using HTTP POST Method and displayed the details on JSP page.

### Technologies used
- HTML
- CSS
- Java Servlet
- JavaServer Pages (JSP)
- Apache NetBeans IDE
- Glassfish Server
- Java JDK 8

### How to run the application
1. Download or clone this repository
2. Open the project in Apache Netbeans IDE
3. Set Glassfish as the project's server
4. Build and run the project
5. Open personal_profile.html in any browser you have
6. Fill in the information details with the right format
7. Click button 'Done' to submit
8. Submitted details will displayed in JSP page
